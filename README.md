# 3D Print Lab — сайт для GitHub Pages

Статический русскоязычный сайт о 3D-печати с адаптивной версткой, 8 страницами, интерактивными возможностями и заготовками подключения счетчиков аналитики. Написан на HTML, CSS и JavaScript, без сборки и серверной части.

## Страницы

- `index.html` — главная
- `technologies.html` — FDM, SLA/MSLA, SLS
- `materials.html` — каталог PLA, PETG, ABS, TPU: фильтры и поиск
- `guides.html` — инструкция, чек-лист с возможностью скачивания
- `calculator.html` — калькулятор стоимости FDM-печати в рублях
- `quiz.html` — интерактивный тест по 3D-печати из 6 вопросов
- `about.html` — сведения о проекте и черновик обратной связи
- `privacy.html` — управление согласием на веб-аналитику



| Событие | Когда действительно отправляется | Пример применения |
|---|---|---|
| `hero_calculator_click` | Нажата кнопка калькулятора на главной | Интерес к инструменту |
| `material_filter` | Нажат фильтр каталога | Разделение по интересам |
| `material_search` | Введен поисковый запрос из 2+ символов | Вовлеченность |
| `calculator_result` | Успешно рассчитана стоимость | Цель 1 / конверсия |
| `quiz_started` | Открыт интерактивный тест | Начало воронки |
| `quiz_answer` | Выбран вариант ответа | Шаг воронки |
| `quiz_completed` | Пройдены все 6 вопросов | Цель 2 / конверсия |
| `quiz_restart` | Повторный запуск теста | Вовлечённость |
| `checklist_download` | Нажато скачивание памятки | Цель 3 |
| `contact_draft` | Сформирован текст вопроса | Интерес к обратной связи |
| `guide_print` | Нажата кнопка печати руководства | Полезное действие |
